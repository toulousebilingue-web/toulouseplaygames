# **App Name**: Toulouse Play Games

## Core Features:

- User Authentication & Profiles: Allow users to register, log in, and manage their profile information including username and avatar. Integrates with Supabase Auth.
- Game Catalog Browsing: Display a searchable and filterable list of board games, showing details like title, description, and player counts.
- Event Creation: Enable authenticated users to create new game events, specifying a game (optional), location, date, time, and max participants. Supports cover image upload via Supabase Storage.
- Event Discovery & Details: Show a list of upcoming events with an option to view detailed information for each, including game details, location, and participants.
- Event Registration: Allow users to register and unregister for available events. Prevents duplicate registrations.
- Event Commenting & Rating: Permit users to post comments and rate events (organisation) and games after attending.
- AI-powered Event Description Assistant: Provide a generative AI tool to assist event creators in writing engaging and compelling descriptions for their events.

## Style Guidelines:

- Primary color: Muted rose-plum (#99606C), evoking the warmth and rich architectural heritage of Toulouse, combined with a contemporary, inviting feel.
- Background color: A very light, desaturated rose off-white (#F9F4F5), providing a clean and subtle backdrop that harmonizes with the primary color.
- Accent color: A vibrant fuchsia (#DE4CBB), selected to add energy, highlight calls to action, and introduce a modern, playful contrast to the primary palette.
- Headline font: 'Space Grotesk' (sans-serif) for its modern, slightly technical yet approachable feel, ensuring strong readability for titles.
- Body font: 'Inter' (sans-serif) for its neutrality, excellent legibility, and versatility, making it ideal for event descriptions, comments, and other detailed text.
- Utilize a consistent set of minimalist line icons for navigation and actions, promoting clarity and a clean user experience aligned with contemporary digital design.
- Employ a responsive, card-based layout for event listings and game displays, emphasizing clear information hierarchy and an intuitive user flow across devices.
- Incorporate subtle, tasteful micro-animations for transitions and user feedback, enhancing engagement without distracting from the core content.
